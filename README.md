# Danish-Rat-King

Only download the .vpk file, everything else is for people to change and compile in csdk12

# Installation

Game files - game - citadel - create a folder named "addon" if it doesnt already exist.

Put the .vpk file into addon folder and change name to pak01_dir.vpk or any number between 01-99: pak15_dir.vpk etc

# Modify in CSDK12

1. Download the game folder and the content folder

2. Go into csdk12 and make a new addon
3. Insert data from game folder and content folder into game and content folder for your new addon respectively
